Self-hosted copies of two D3 visualizations. Their original GitHub Pages sites load JavaScript libraries over plain http://, which browsers block on HTTPS pages.

    Lauren Wood, 2015, Harvard CS171 final project.
    Original repository: github.com/laurenwood/laurenwood.github.io
    Original site: laurenwood.github.io
    Unmodified mirror apart from the HTTPS fix: the insecure http:// library URL now points to a local copy, and the font and video links use https://.
